Մուտք ադմին

Մուտքագրեք գաղտնաբառը՝ կայքը խմբագրելու համար։

Ադմինի կարգավորում

Մեկ անգամ է արվում։ Պետք է GitHub տոքեն, որը թույլ է տալիս փոխել կայքի ֆայլերը։

  1. Բացեք github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → ընտրեք կայքի ռեպոզիտորիան
  3. Permissions → Repository → Contents: Read and write
  4. Generate token և պատճենեք այն այստեղ
